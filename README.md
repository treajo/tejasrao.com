# tejasrao.com

Personal site for Tejas Rao. One hand-written HTML file, no build step and no dependencies.

- `index.html` — the whole site: markup, styles and the guide RNA finder.
- `CNAME` — the custom domain, read by GitHub Pages.

## Editing

Open `index.html` in any editor and save. Commit and push, and the live site updates in about a minute.

## Hosting

GitHub Pages serves this repository from the default branch, root folder. The domain `tejasrao.com` is registered at GoDaddy, with DNS pointed at GitHub Pages.
